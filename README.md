# Finance Brain

App de Finance do Grupo Shaken: tesouraria, faturas, aprovações, despesas, cartões, CdG e RH.
Next.js (Vercel) + Supabase (UE) + Claude API. O Primavera continua a ser a fonte de verdade contabilística.

- Specs validadas: `specs/`
- Base de dados: `supabase/migrations` (estrutura, acessos, registo de alterações) e `supabase/seed` (dados iniciais)
- Ligar um ambiente: `docs/LIGAR_AMBIENTE.md`
- Estado do projeto: PMO (artefacto no claude.ai)
